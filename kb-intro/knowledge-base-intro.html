一、为什么要建

一句话：这是给公司办文化活动的人（HRBP / 文化 BP）准备的"点子弹药库"。

以前办活动
  • 凭个人经验，临时上网搜
  • 好点子散落公众号、官网、别人复盘里
  • 每次都从零想，重复造轮子
  • 适合"领导也在场"的点子尤其难找
  • 人一走，经验就断档
AI 知识库
  • 自动搜并筛选点子，不用人工攒
  • 按"对谁用"分类（上下级 / 高管间）
  • 卡片墙网页，点开链接即看
  • 团队三端共享，谁都能用
  • 持续累积，经验不流失

二、怎么建（采集流水线）

没雇人手工整理，而是搭了一个会自己跑的"采集机器人"，按固定流水线把点子变成卡片。

1

定主题清单

6 类活动：员工大会 / Offsite / 破冰 / 颁奖 / Open Day / 下午茶研讨。

2

AI 自动上网搜 + 判来源

区分一手（官方 / 主办方）与二手（媒体 / 经验贴）。

3

六维评估 + 关系适配

过滤平级 / 朋友向内容，只留上下级与高管间（详见第五节）。

4

落成知识卡 → 卡片墙网页

每张卡含摘要 / 来源 / 类型 / 关系 / 评分，铺成可翻的网页。

5

三端同步

网页（GitHub Pages）+ 个人笔记（Obsidian）+ 团队空间（乐享），三方一致。

三、过程中的关键考虑

建的时候卡在最重要的一条判断：活动点子要看"对谁用"。

关系分层（最核心）

朋友间玩的破冰（两真一假、互画肖像）放到"领导和员工""领导和领导"场合就不合适。所以硬性分层：整个库只保留上下级和高管间两类，平级 / 朋友向一律不要。这是它和"普通灵感收集"最大的区别。

来源可信度

优先用官方 / 主办方的一手资料；二手（媒体报道、经验贴）会醒目标注"二手·供参考"，只在缺一手时保留。

不碰敏感内部资料

某些安全 / HRBP 内部空间明确列为禁区，采集程序自动跳过，避免把不该外传的内容收进来。

点开即看

所有卡片做成单文件网页，不用装任何软件，发个链接就能打开，方便转发。

四、后面是怎么决策的

建完不是一成不变，几个关键决策都是边跑边定的。

周报口径

按"卡片数"还是"页面数"算账？最后定主口径用页面（一个活动主题 = 一页），卡片数当辅助，避免数字虚高。

发群通道

原以为用普通"群机器人"网页钩子就能发，结果是"智能机器人"要走长连接；且主动发不支持 @ 所有人。决策：去掉 @，每周五自动化直接发文案 + 海报图。

连通误报

乐享后台显示"断开"，实测是显示滞后。改成"探活"机制确认真连通，不再被假红点骗。

五、持续运营 与 质量把关

两件事绑在一起：左边让系统一直转，右边让它不出错。

持续运营
  • 采集机器人每 6 小时自动轮询更新
  • 每周五 17:00 自动生成周报（新增几页 / 几卡 / 删几重复）
  • 周报自动发到团队群
  • 写好了交接文档，人走也能接手
  • 凭证与配置存好复用
质量把关
  • 进门关：六维评估 + 关系适配
  • 源头关：一手 / 二手标注
  • 去重关：重复 / 平级内容剔除（留日志可追溯）
  • 沉淀关：只沉最终有效，不放草稿
  • 治理关：不碰敏感内部资料

六、六维评估到底是什么

每一张候选卡片，都要过这 6 个维度的打分，全部达标才进库。维度来自知识采集自动化 skill 的硬性评估标准。

1–5 分维度 1 · 相关度

这条点子跟"我们要办的活动主题"贴不贴。跑题的直接低分，不进库。

1–5 分维度 2 · 权威性

来源可不可信。官方 / 主办方一手资料加权；二手必须标注"二手·供参考"，只在缺一手时保留。

1–5 分维度 3 · 时效性

内容是否过时。已停办的活动、失效的旧平台玩法等降分。

1–5 分维度 4 · 去重度

跟库里已有内容重合度低才保留。重复的一律不进，留更全更权威那版。

1–5 分维度 5 · 可落地质量

拿回去能不能直接用。有明确流程、成本可控、可执行，而不是空泛概念。

1–5 分维度 6 · 关系适配度（新增硬维度）

跟"对谁用"匹不匹配。平级 / 朋友向内容拿去上下级或高管场景，直接判低分；跨档从严。

打分规则：每个维度 1–5 分，任一维度 < 3 直接淘汰。一手来源放宽阈值（权威性可松一点），但关系适配度对跨档内容一律从严——平级向内容用于上下级场景，直接判低分不进库。
