三、一手源清单（按可挖性）

  • 各地证监局"投资者/媒体开放日"范式（csrc.gov.cn 各局）
  • 上市公司投资者接待/调研管理办法（cninfo 披露 PDF）

  • 腾讯/字节/阿里员工大会官方稿与视频
  • 头部科技公司管理层 Offsite 战略务虚会官方回顾
  • 行业颁奖典礼官方 SOP 与致辞

  • Offsite 议程原稿与会后复盘
  • 表彰典礼官方视频、HR 公众号官方复盘
  • KM / 乐享内部活动 SOP 与复盘帖

🛠 工具官方文档

  • 腾讯会议 / 腾讯文档 / 抽奖等内部工具官方手册
  • 活动平台官方最佳实践

五、目标与里程碑

🎯 目标：一手率 10% → 30%+

  • Q1（即时）：OpenDay 一手扩至 12+；新增 2~3 张制度范式卡。
  • Q2：员工大会 / Offsite 各补 5+ 张一手（大厂官方回顾）。
  • Q3：表彰 / 下午茶 / 破冰各补 3+ 张一手；启动内部征集。
  • 验收：被引用时"来源"栏一手源占比 ≥ 30%，四大空白主题归零。

六、落地机制（写进自动化）

⚙️ 让补采自动发生

  • 补采脚本内置"一手种子源"清单（监管官网 / 大厂官网点 / 内部工具文档），每轮优先检索。
  • 评估阶段对一手源额外加权（权威性满分），降低淘汰阈值。
  • index.json 严格标注 sourceType，周报看板监控一手率曲线。
  • 空白主题（员工大会/Offsite/表彰/下午茶）标记"待补一手"，轮询时优先命中。
