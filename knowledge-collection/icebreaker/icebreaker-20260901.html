高管入职·书面领导宪章 + 30-60-90 节奏 + CEO 握手

高管入职对齐高管间二手

高管入职不是 HR 迎新，是业务关键过渡计划——把高风险任命转成运营结果。核心四件：①上任前写「领导宪章」（业务背景 / 角色为何现在存在 / 第一年 Top3-5 成果 / 需高管或董事会批准的事项 / 约束），非 recycled JD；②建「利益方地图」而非会议日历——标注正式决策者、影响者、关键客户、董事会、可能受影响的领导者，并点名摩擦点（如新 COO 要标准化交付却被产品/销售历史抵制，假装没冲突=准备不足）；③设 30-60-90 节奏（诊断期有截止→书面优先级观点→跨职能决策节奏→90 天复盘对照原始授权），防两种失败：信息不全就动 / 无限诊断装深思；④CEO 亲自负责「领导握手」——首月每周 1:1（学到啥 / 哪些假设被证伪 / 哪些决策被卡 / 哪需 CEO 清路）；最危险信号：CEO 沉默=缺乏背书。

怎么做
上任前书面锁定领导宪章（成果+决策权+约束）；给利益方地图并点名摩擦点；30-60-90 四非妥协（诊断/书面观点/决策节奏/复盘）；CEO 首月每周握手 1:1，沉默=不背书。
🔗 summitexecutivesearch.com/2026/07/17/executive-onboarding-best-practices-guide
适用：③ 高管入职（CEO / 董事会 / PE 视角）——书面领导宪章 + 利益方地图 + 30-60-90 + CEO 握手，把高风险任命变运营结果（高管间，治理层，非游戏）。

C-Suite 入职·授权书先于上任 + 情报简报 + 董事会-CEO 对齐

C-Suite 入职高管间二手

高管入职是任命最后一阶段，非行政交接。核心：①接受任命即定义「授权书」——授权书≠JD，写清为何聘 / 决策权 / 约束 / 早期衡量指标（如「两季度内重建管道质量 + 预测问责 + 重置 GTM 覆盖」）；②预组「情报简报包」（战略计划 / 运营指标 / 财务市场背景 / 领导团队简介 / 董事会材料 + 一年内变与未决的叙述），让首周问更锋利的问题而非重建事实；③董事会面角色（CEO / 董事长）显式对齐沟通节奏、决策权、监督与运营介入边界——新高管能扛高期待，但扛不住分渠道传来的冲突期待；④首 30 天纪律诊断（对同级 / 下级 / 客户 / 一线问一致问题：什么在运转 / 决策卡哪 / 哪些假设失效 / 最大风险 / 团队要新领导做什么），但立即控制问题（人才 / 客户 / 执行缺口）仍要基于事实快决。

怎么做
接受任命即出书面授权书（成果/决策/约束）；预组情报简报包（非文档洪流）；董事会-CEO 显式对齐沟通节奏+决策权+监督边界；首 30 天一致问题诊断，控制类问题基于事实快决。
🔗 scionretainedsearch.com/2026/08/01/guide-to-c-suite-onboarding
适用：③ C-Suite 入职（董事会 / CEO / 创始人视角）——授权书先于上任 + 情报简报 + 董事会对齐边界（高管间，治理层，非游戏）。

高管入职·团队初见 + 1:1 倾听问题 + 半日信任工作坊

高管-团队融合高管间二手

顶级寻聘机构 Spencer Stuart 的高管入职框架：①先在更广团队前做视频 / 晚餐的「相互认识」初见——CEO / hiring exec 简短互介后留 1 小时纯认识，理想在职场外（晚餐）或进行视频；②随后与直属团队 1:1——视频缺了咖啡闲聊，有意识地前几分钟个人热身显人性，会前发「倾听问题」清单（你在这多久 / 什么在变 / 你喜欢这的什么 / 想改什么 / 你的角色如何助公司达标 / 我前三月该聚焦啥）；③用心理测评工具（Individual Style Profile + Culture Framework）在半日工作坊帮团队了解彼此偏好工作方式、建信任；④同步建利益方地图（董事 / 同级 / 内外部），按动机与互动类型定沟通策略，定期（年中 / 年末）回查。

怎么做
团队初见（CEO 互介后留纯认识时间，职场外最佳）；直属团队 1:1 前发倾听问题清单+个人热身；半日心理测评工作坊建信任；利益方地图按动机定沟通策略+定期回查。
🔗 spencerstuart.jp/research-and-insight/managing-technology-enabled-executive-onboarding-and-transitions
适用：③ 高管入职团队融合（Spencer Stuart）——初见 + 1:1 倾听问题 + 半日信任工作坊 + 利益方地图（高管间，非游戏）。

新任 CEO 90 天路线图·董事会破冰 + 战略 Offsite + 100 天复盘

新任CEO入职高管间二手

新 CEO 首 90 天决定信任与战略方向。D1-5：见董事长与关键董事对齐期望与即时优先；与执行团队每人简短 1:1 了解角色 / 优先 / 挑战。W2-4：跨职能简报（财务 / HR / 营销 / 销售 / 产品）、客户洞察、与一线及支持员工小组会看文化、部门旁听、HR 协作人才 / DEI、外部利益方（客户 / 供应商 / 伙伴）。M2：执行团队战略 Offsite（愿景 / 战略支柱 / KPI）+ 速赢 + 跨职能工作坊建问责 + 内部「Ask Me Anything」倾听 + 敬业度数据复盘。M3：职能深潜 + 执行团队 1:1 路线图 + 向董事长与董事会做 100 天正式复盘（发现 / 优先 / 调整）+ 常态反馈回路。持续：董事会季度更新 + 年度战略复盘、员工倾听会、批准举措落地。

怎么做
D1-5 董事会+执行团队 1:1 对齐；W2-4 跨职能简报+一线文化小组会；M2 战略 Offsite+速赢+跨职能工作坊+AMA 倾听；M3 100 天董事会复盘；持续董事会季度更新+员工倾听。
🔗 galvinrowley.com.au/ceo-onboarding-plan
适用：③ 新任 CEO 90 天入职（董事会 / 执行团队视角）——董事会破冰 + 战略 Offsite + 100 天复盘（高管间，治理层，非游戏）。

越级会谈·HR 官方引导手册（问题库 + 留任访谈 + 数据背书）

越级会谈上下级一手

南卡大学 HR 官方指南：越级会谈（senior leader 与下级的下级员工对话）传递「你的反馈重要」信号，数据背书——与高管对话的员工 37% 更投入(Gallup 2022)、82% 员工认为高管应更频互动(Edelman 2023)、高管直接对话早识别运营风险 +25%(HBR 2021)。时机：敬业度倡议 / 定期反馈 / 组织变革 / 表彰发展 / 不确定期。流程：准备（测信任水平、从心理安全感起、发意图与问题、选咖啡等非正式场景）→进行（重申保密、开放式问题、正向接纳）→跟进（记要点、闭环、定期回查）。附问题库：开场 / 日常 / 对领导反馈 / 团队动态 / 成长 / 收尾 6 类；含 Stay Interview（留任访谈）记录模板。

怎么做
时机选在组织变革/敬业度/不确定期；准备先测信任、发意图与问题、用咖啡等非正式场景；进行重申保密+开放式问题；跟进记要点闭环+定期回查；配 6 类问题库+留任访谈模板。
🔗 sc.edu/.../manager_guide_facilitating_impactful_skip_level_conversations.pdf
适用：② 越级会谈（HR 官方引导手册）——数据背书 + 6 类问题库 + 留任访谈模板 + 保密与闭环纪律（上下级，leader↔跨层员工，避免变考核中层）。

越级会谈·问题银行 + 30 分钟模板（不评经理）

越级会谈上下级二手

Culture Amp 框架：越级会谈问题分三块——对经理支持（收到反馈频率 / 成长支持 / 目标清晰度 / 提异议舒适度 / 被倡导感 / 自主权 / 认可 / 求助意愿）、对组织（日活如何连战略 / 信任领导层 / 文化描述 / 「若当一天 CEO 改啥」）、对变革（感受 / 未答疑问 / 沟通有效性 / 过渡支持）。关键：问「你的经理哪做得好」而非「你怎么看经理」避免变人格审判；不评绩效。30 分钟模板：3min 破冰 + 5min 谈工作 + 15min 反馈洞察（多听少说）+ 5min 答员工问 + 2min 收尾承诺。员工侧提示：收到上级的上级邀约别慌，不是评估。

怎么做
问题分经理支持/组织/变革三块，问「经理哪做得好」避人格审判、不评绩效；30min 模板破冰→工作→15min 反馈(多听)→答问→收尾承诺；员工侧先安抚非评估。
🔗 cultureamp.com/blog/skip-level-meeting-guide
适用：② 越级会谈（问题银行 + 30min 模板）——经理支持 / 组织 / 变革三块 + 不评绩效 + 多听少说（上下级，leader↔跨层员工）。

新经理入职清单·1:1 实操机制 + 决策权书面化

新经理入职上下级二手

新经理最缺的不是理论是机制：①怎么开 1:1（频率 / 时长 / 覆盖什么 / 何时闭嘴听 vs 给反馈；多数要么跳过要么变状态汇报）；②怎么给反馈不伤人（DDI：57% 员工因管理差离职，多因反馈太少 / 太狠 / 太虚）；③怎么开硬谈话（绩效 / 冲突 / 老油条）；④决策怎么定（每公司不同，须懂真实文化非价值观海报）。落地：上任前发团队介绍信（warm 但 pro）；D1-2 团队短会听需；W1 每人 30min 介绍（非正 1:1：「你的角色 / 啥顺 / 啥烦 / 偏好怎么沟通」）；W2 设周 / 双周 1:1 节奏；建「倾听之旅」文档记模式（6 人同投诉即焦点）。决策权必须书面化：预算权($500 / $5k / $50k?)、招解雇权、流程变更权——写不清就乱花或不敢花。

怎么做
上任前发介绍信；D1-2 短会听需；W1 每人 30min 介绍式 1:1；W2 设 1:1 节奏+倾听之旅文档；决策权(预算/人事/流程)书面化写清阈值，避免滥花或不敢花。
🔗 tallyfy.com/new-manager-onboarding-checklist
适用：② 新经理入职（清单式）——1:1 实操机制 + 反馈 / 硬谈话 + 决策权书面化（上下级，新经理↔团队，避免只发培训 deck 不落地）。

新经理首场员工会·45 分钟议程 + 会议节奏

新经理首会上下级二手

新经理首场员工会定调后续关系。45 分钟模板：5min 问候 + 自我介绍 + 请新成员自我介绍；5min 破冰活动；15min 问团队优势 / 挑战 / 你上任想改啥 / 想保留啥；10min 开放提问。节奏：首会后定会议频率（日 / 周 / 双周 / 月依团队与目标，如截止前项目日会、内向团队少会多专注）；平衡全员会 vs 1:1（按团队规模与需求，至少周 / 双周）；建个人关系与建团队文化同等重要。FAQ：议程含暖开场 + 背景 + 目的目标 + 期望责任 + 问答；用 icebreaker 显可接近；坦诚回应焦虑、承诺后续解决。

怎么做
45min 模板（问候自我介绍 5 / 破冰 5 / 优势挑战+想改想留 15 / 开放提问 10）；首会后定会议频率(依团队目标)；平衡全员会+1:1(≥周/双周)；用破冰显可接近、坦诚回应焦虑。
🔗 workleap.com/blog/new-manager-first-staff-meeting
适用：② 新经理首场员工会（45min 议程 + 节奏）——破冰 + 优势挑战 + 想改想留 + 开放提问（上下级，新经理↔团队，定调关系）。

越级会谈·议程模板 + 20 问 + 中层不在场纪律

越级会谈上下级二手

Engagedly 实操：参与者——资深领导(VP / 总监 / C-level，角色是听、问、忍住不现场解决，非评估 / 审计 / 承诺)；员工(个人贡献者或下层，提前知会非绩效谈话)。关键纪律：被「跳过」的中层经理不应在场（在场即变味、坦诚归零），但事后把聚合主题(非个人归属)分享给经理，不让他蒙在鼓里。议程 30-45min：会前 1-2 周发目的(非绩效、纯倾听) + 2-3 样例题 + 告知经理；开场 5min 重述目的 + 保密 + 低 stakes 破冰；核心 20-25min 问 3-5 个聚焦开放题(日活 / 团队动态 / 成长 / 文化方向 / 创新)；收尾 5-10min 问遗漏 + 下一步 + 真诚致谢；会后聚合主题跨会谈(非个人)、与经理分享非敏主题、向员工反馈闭环、跟踪未决。附 20 问分日活 / 团队管理 / 成长 / 文化方向 / 创新五类。

怎么做
中层经理不在场(事后聚合主题分享、不蒙鼓里)；30-45min 议程(会前发目的+样题+告经理 / 开场重述目的保密 / 核心 3-5 聚焦问 / 收尾下一步致谢)；会后聚合主题跨会谈+向员工闭环，附 20 问五类。
🔗 engagedly.com/blog/what-is-a-skip-level-meeting-and-how-to-conduct-one
适用：② 越级会谈（议程 + 20 问 + 中层不在场纪律）——被跳过的经理事后收聚合主题、非评估非承诺（上下级，leader↔跨层员工）。

新团队首会·6 要素议程最佳实践

新团队首会上下级二手

无论新经理接新队或老手接新队，首会定调。6 要素：①自我介绍让团队认识你（含破冰 fun fact）；②团队成员视角（团队强项 / 待改进 / 兴奋点，给新领导挖信息）；③你的领导哲学（动机 / 管理风格 / 团队愿景，高层但让人认识你）；④期望与规则（会议节奏 / 邮件沟通 / 目标追踪，求对齐）；⑤Q&A 开放讨论；⑥下一步（复盘 + 后续 1:1，显组织力）。最佳实践：提前发议程、限 60-90min、留有机讨论空间、每节计时、做笔记显在听、收尾给明确下一步。样例议程：10:00 欢迎 + 破冰 fun fact / 10:15 团队视角 / 10:30 领导哲学 / 10:45 期望规则 / 11:15 Q&A / 11:25 下一步 / 11:30 散。

怎么做
6 要素(自我介绍+破冰/团队视角/领导哲学/期望规则/Q&A/下一步)；提前发议程、限 60-90min、每节计时、做笔记显在听、收尾明确下一步；样例 90min 时间盒。

适用：② 新团队首会（6 要素最佳实践）——破冰 fun fact + 团队视角 + 领导哲学 + 期望规则 + Q&A + 下一步（上下级，新经理↔团队，定调后续协作）。
