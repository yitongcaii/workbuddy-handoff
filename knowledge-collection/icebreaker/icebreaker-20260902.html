独立董事首任·首次董事会 + Induction 清单（来治理，不来旁观）

治理层破冰高管间二手

新任独立董事的「破冰即治理」清单：①业务实质暴露——财务负责人须把管理口径与法定报表对齐、讲清现金转换/契约条款/关联方往来；业务负责人自己说出「哪些假设不成立计划就崩」；内审与合规不经管理层「消毒」直接讲控制缺口与在办调查。②现场暴露——去工厂/门店/医院/数据中心，且要看难点与例外场所，而非管理层为礼节性参观准备好的最新样板；目的是听懂运营语言、验证董事会报告与现实是否一致，不是对员工下指令。③映射权限与保护性上报路径——章程、保留事项、授权表、董事会日历、各委员会章程、子公司监督，以及决策如何从管理层走到委员会再到董事会；同时认清 chair、资深独立董事、公司秘书、合规官、内审、外审与举报路径分别是谁；仅有一张组织架构图是不够的，若高管能在重大审议中延迟或过滤你接触保证职能，权限图就是虚的。④首次会议不急于证明价值——读全套材料与历史纪要，逐项识别「这个议题的选择/法律依据/财务后果/相关方影响/利益冲突/后续跟进」；材料到得太晚而事项不可逆时，提议延期比带着不完整信息表现决断更负责。⑤首会也是文化测试——看异议是否被公正记录、高管是否直接回答、冲突是否在讨论前申明、行动责任人是否带证据回来。⑥90 天把 induction 转成学习计划——问「什么改变了我最初的理解」，对毛利、文化、监管关系或决策权的惊讶点，恰恰暴露 induction 的薄弱环节。

怎么做
前置索取章程/授权表/委员会章程/董事会日历+独立索取信息的流程；分头会谈财务、法务、合规、内审、外审与关键业务负责人（不接受统一口径）；调阅在办调查、监管往来、举报事项与未来两个会期要决的事；首会只做「问清假设 + 确认谁拥有下一个判断」；会后核对纪要实质准确性并确认跟进事项；90 天与 chair 复盘理解偏差、按结果补课。

适用：③ 治理层首次会议（新任董事↔管理层/董事会）——以专业与治理责任切入，非社交游戏；可迁移为「新高管进入既有班子」的首月对齐清单。

新任董事被评价的是「前 90 小时」而非前 90 天（AICD 七步 + 误区）

新任治理者前90小时高管间一手

澳洲公司董事协会（AICD）访谈多位资深董事得出的反直觉结论：多数董事不是在前 90 天被评价，而是在前 90 小时——治理场没有教科书说的三个月宽限期。七步与常见误区：①先见关键人——最好在签字前就见 chair 与 CEO 确认文化契合度，尽早见齐高级管理团队；见供应商/客户/监管等其他相关方的时机听 chair 建议。②提前有备而来——审阅近期董事会材料，理想情况下 induction 包应包含章程、最新年报、组织架构图、行为准则、董事会与各委员会章程；「没有提供完整 induction 包，本身可能就是一个红旗」。③做尽调——理解行业、公司业绩、主要挑战与董事会正在审议的事项；尤其细看现金流预测（最能反映财务困境），并对董事会与公司文化做尽调——chair 与 CEO 的说法未必定论，特别是当他们本身就是问题所在时。④进了会议室别太快说太多——资深董事 Arlene Tansey 复盘首次董事会：从高管到董事的身份转换比当时意识到的更大，「若重来，我会前两次会议只看与听再开始贡献」，并把「你们应该这样做」「我以前这么干过、没用」这类措辞从表达里去掉，换一种方式表达同一观点。⑤早期别一上来就压合规细节。⑥可通过公司秘书/法务秘书、投资者关系索取最新券商报告或自己做行业研究。

怎么做
上任前会见 chair + CEO + 高管团队做文化契合确认；索要完整 induction 包并核对是否齐全（缺失即红旗）；读近三次董事会材料 + 现金流预测；前两次会议以观察与倾听为主，发言先换措辞（不用「你们应该」）；早期不主导合规议题；通过公司秘书/IR 拿券商报告与行业研究。

适用：③ 高管/治理层新任融入（AICD 官方 · 在任董事逐字复盘）——「先听后说 + 换措辞」是空降高管进班子同样适用的破冰纪律。

董事会 Induction 怎么设计：Chair 主责 · 秘书运营 · orientation ≠ induction

Induction 项目设计高管间二手

董事会 induction 是结构化过程，不是一个文件包。责任分工：Chair 定调（保证内容反映董事会战略优先级与文化），公司秘书负责日程、文档与后勤；CEO 与高管团队负责战略、业绩与关键风险简报；各委员会主席亲自给新入委成员讲该委员会的授权、在办工作流与未决议题；若入职者本人就是 chair，则由资深独立董事或副主席主持以保客观与连续性。内容六块：治理与法律框架（章程、董事会章程、委员会职权、适用法规、董事义务与责任）；战略与业绩（当期战略计划、关键指标、近期财务结果、重大风险与机会）；董事会运作（会议排期、决策协议、信息流、与管理层的关系、常设议题）；文化与动态（董事会工作风格、既有关系、张力与共识区、塑造实际运作的不成文规范）；相关方图谱（关键投资人、监管、大客户或出资方）；现场走访与管理层见面（文件无法替代的直接暴露）。周期通常 3-6 个月而非压缩成一天：前几周打基础（治理文件、财务状况、与 CEO 及高管见面），随后几个月通过委员会参与、现场走访与非正式对话加深；赶进度是治理风险——未被妥当 induction 的董事更容易服从主导声音、错失关键背景、或提出拖慢审议的问题。orientation 只是 induction 的子集：前者答「要开始需要知道什么」，后者答「要贡献到组织所需水平，需要理解、经历并内化什么」。

怎么做
明确 Chair 主责 + 公司秘书运营 + 委员会主席分头简报的三角；按六块内容排 3-6 个月节奏（前几周基础，后续深化）；把「文化与不成文规范/既有张力」写进正式议程而非只发文件；按个人背景定制深浅（财务出身少做财务扫盲、跨行业加行业导入）；不要把 orientation 当作全部 induction。

适用：③ 治理层融入项目设计（Chair/公司秘书/委员会主席分工）——可直接改造为高管班子「新成员进入」的 3-6 个月融入项目模板。

首会前必修清单高管间一手

新组建高管班子·半日对齐工作坊真实案例（收购后创始合伙人退出）

新班子对齐工作坊高管间二手

真实一线案例：英国一家大型科技公司被收购、创始合伙人离场后组建全新高管团队，面对高增长目标必须极快起势。外部引导团队用「3 次短会 + 半日工作坊」加速三件事——清晰（给团队空间摊开各自对团队目的、主要优先级、能更好协作的方式、以及如何衡量影响的假设；把多元观点摊出来才能发现并处理冲突观点）、对齐（把隐含变显性后写下来：Purpose、Mission、Strategies、Roles、Accountabilities、Domain 管辖边界、Working Agreements）、信任（让团队真正互相了解，并对彼此设定期望，从而有安全空间开启这些关键对话）。具体做法：先与总经理开 3 次短会摸组织、并共创团队宪章草案（愿景、使命、目标、角色）；再设计并主持半日工作坊——前三分之一时间专门用于彼此认识，通过一串短练习创造「打开自己」的时刻，让成员更深理解彼此的动机、影响来源与工作风格（非幼稚游戏）；短休后用余下时间把宪章做实，通过一系列练习与建设性对话澄清目的、愿景、目标、角色与问责、管辖域、策略、会议节奏与协作约定。工程负责人评价：外部引导帮团队跳过了 forming 阶段常见障碍。

怎么做
会前与一号位开 3 次短访 + 共创宪章草案；半日议程 = 1/3 相互认识（动机/影响者/工作风格短练习）+ 2/3 宪章八要素定稿；坚持「先把隐含假设摊开、再落文字」；用外部引导师避免一号位既当主持又当表态者。
🔗 thisiskindred.co/helping-a-newly-formed-leadership-team-accelerate-clarity-alignment-and-trust
适用：③ 新组建高管班子首场对齐（并购/换届后）——认识环节服务于宪章产出，适配高管间「专业切入、不做游戏」。

高管团队宪章 / Terms of Reference：决策范围 + disagree & commit + 让吵架变安全

高管团队宪章高管间二手

高管团队（高级管理团队、C-suite、董事会）的宪章要解决高风险决策、强势个性、部门筒仓与顶层统一的问题，写三件事：①企业级目的与范围——别停在「领导公司」这种空话，要写清哪些决策集体做、哪些个人做（示例：「领导团队集体决定公司战略、年度预算分配与关键任命；各成员各自运营其职能，把跨切议题带回团队」），既防事情掉进缝里（neglect），也防互相插手（overreach）；很多领导团队失败正是因为没搞清哪些决策该集体做。②决策机制与会议节奏——写明大决策怎么定（共识 / 一号位定 / 投票）以避免权力拉扯；常见规范是「disagree and commit」：会上激烈辩论，一旦定了，全体高管对外以一个声音支持——宪章里可直接写「决策一旦作出，我们对外一个声音」；同时约定必要的保密边界（敏感话题不出这个团队，除另有约定）；节奏可为周例会 + 季度 offsite；若会议一直低效，就在宪章里加结构（议程、禁设备等）。③行为规范——「让吵架变安全」：挑战想法而非挑战人、房间里可以异议、不因诚实输入而报复或记仇，并保障发言时间均等以防最大声者主导。补充：顶层若没明确「我们怎么一起工作」，组织其他部分很难顺畅；大团队或远程可用协作白板与问卷高效收集输入，分小组分头起草不同章节（一组写沟通规范、一组写决策机制）再合并；重要班子常请外部引导师或教练保证参与均衡；宪章应可迭代（例如周会改双周）。

怎么做
列「集体决策 vs 个人决策」清单；确立 disagree-and-commit + 对外一个声音 + 保密边界；行为规范三条（挑战想法不挑战人 / 可当场异议 / 不报复记仇）+ 发言时间均等机制；分组起草再合并、必要时请外部引导师；约定复盘与迭代节奏。

适用：③ 高管班子协作规则固化（含决策权边界与冲突安全）——比破冰活动更硬的高管间信任基础设施。

经理操作手册（Manager Operating Manual）：5 大块 · 2-3 页 · 白话写

经理操作手册上下级二手

数据点：73% 新入职者说「上级期望不清」是他们最大的早期挫败，但多数领导从不把自己实际怎么工作写下来，代价是数周的无谓困惑、信任消耗与本可早日贡献的人才在翻译中迷路。典型场景：新人周一入职，你正忙季度末，消息接连来——「你更想快速通个电话还是我写下来？」「路线图文档我可以不经你更新吗？」「你看到我的休假申请了吗？」这些问题都不无理，但一周下来双方都觉得在各说各话；这类早期摩擦通常不是能力问题，而是未言明的期望。经理操作手册（也叫 manager README / leadership user manual）就是在误解点燃前把期望显性化，本质是「关于你这个管理者的 readme」。五块内容：①目的与价值观——驱动你决策的原则（例：「透明高于政治。若你对某个决定有疑问，直接问我，别在同事间猜」）；②沟通规范——各渠道怎么用、多快回，要具体（「核心时段 9-5 每 2 小时看一次消息，力争 4 小时内回；紧急发短信；偏好异步更新而非状态例会」）；③工作偏好——1:1 怎么开、怎么评审工作、数据不全时怎么拍板（「每周 1:1 是神圣时间，除真正紧急不改期；你带议程，我提前 24 小时补我的」）；④支持与成长——什么算「好」、如何授权、乐于给什么样的辅导（「我授权结果、不授权任务：说清成功什么样，然后你拥有怎么做；我在这儿陪你想问题，不是替你微观解题」）；⑤可用性与边界（核心时段、什么算紧急、休假期间找谁）。写法：控制 2-3 页、大白话，没人需要读小说。五项收益：新人从第一天就看得见护栏、上手更快；减少微摩擦（不再有「打扰您了」式焦虑）；写的过程逼你把领导信念说清（有时还会修正它）；公开后团队可拿它对账你的言行差距；向组织释放「我认真对待清晰与心理安全」的信号。

怎么做
按五块（价值观/沟通规范/工作偏好/支持与成长/可用性与边界）写 2-3 页大白话；把响应时效、1:1 规则、授权方式写成可验证的具体句子；发给团队并明确「发现言行不一可当场指出」；当作对话起点而非规则清单；随团队与自身变化更新。

适用：② 新经理上任/新人入职期望对齐——把「未言明的上级期望」写成文档，降低上下级猜谜成本，不涉隐私。

Manager README 官方模板 + 七类反面风险（别写理想版自己）

README 模板 + 风险上下级一手

工具官方模板给出可直接填的九段结构：个人简介、写这份文档的原因、管理哲学、偏好沟通渠道、工作伦理与问责、决策自主度、反馈与持续改进、对 1:1 的立场、个人价值观。定位说明：README 的目标是公布一份「说明什么对你重要、和你共事是什么体验」的文档，既帮潜在或现有下属理解你，也是写作者自身的内省工具；这种「有意的示弱 + 公开个人与专业核心价值」本身就是建信任的动作。更值钱的是模板同时列出的七类反面风险与提醒：①可能显得单向——README 讲的是管理者偏好，但领导力是双向关系，写得太刚性会打消协作或阻碍向团队需要调整；②可能造成权力失衡——变成「我就这样，你自己适应」的姿态，员工可能感到被迫顺从而不敢表达自己的需要；③有变静态的风险——管理风格应随团队、公司文化与个人成长演进，长期不更新就会过时失效；④可能被误读为规则清单——写得差就像一串要求，让人觉得被微观管理或被框住；⑤替代不了真实沟通——文档无法取代关于期望、反馈与团队动态的持续对话，有人会过度依赖文档而不再谈；⑥可能无意暴露偏见——对偏好的描述可能无意排除某些性格或工作风格，让部分员工觉得不被看重；⑦可能设定虚假期望——若写的是理想化的领导风格而实际并非如此带团队，反而制造不信任与失望。结论：把 Manager README 当作「开放讨论的起点」而非规则集合，并配以定期反馈回路，确保与团队需要保持对齐。

怎么做
用九段结构起草（简介/为何写/管理哲学/沟通渠道/伦理与问责/决策自主度/反馈机制/1:1 立场/个人价值观）；发布时明说「这是讨论起点不是规矩」；配固定反馈回路（每季问团队哪条名不副实）；随团队与文化变化更新；逐条自查七类风险，尤其别写理想版自己。

远程/分布式团队的「个人使用手册」怎么写（含适用性辩论）

远程上下级手册上下级二手

远程团队里 manager README（personal user manual）的用途：把管理者的价值观、性格、领导风格与期望在真正互动之前传达给直接下属，从而改善组织内沟通与生产力；文档描述的是「这个人」而不是公司，名字来自软件目录里的 README——告诉你怎么用这个软件，manager README 同理，说明与你沟通的最佳方式与你所坚持的原则，可以写得很专业也可以很有人情味。重要边界：不要把它做成穷尽的规则集，而应当成一种能提升工作关系效率的机制——团队建设与沟通的基本功仍要按传统方式做。写法要点：①引言——简短说明你是谁、为什么写这份手册、希望从中得到什么，甚至怎么走到今天这个岗位；遵循 TL;DR 原则别啰嗦，可放一两张照片（本人、宠物）；示例：Etsy 的高级工程经理 Matt Newkirk 在「Matt, as your manager」标题下只用不到五行说明意图与支持承诺。②说明你的角色——工作风格与在业务中的更大目标、典型工作时间与工作风格偏好；随后加入你对下属的承诺（做成「我能怎么帮你」小节：持续提供背景与更新、给外部视角、为团队成员的成功喝彩），显示你也愿意担责，读起来更有邀请感。③一起工作怎么做——最关键一节：写清你对远程下属的期望、你偏好的沟通方式、以及你怎么帮他们做到最好；按沟通渠道说明响应时效（邮件一般多久回？若需更快该走哪条通道），说明你以什么形式给反馈、1:1 如何组织与多久一次，并告诉团队如何解读你的日历（日历必须共享）。

怎么做
按「引言（TL;DR）→ 角色与我能怎么帮你 → 一起工作怎么做」三段写；每条写成可验证句（各渠道响应时效、反馈形式、1:1 频率与结构）；共享日历并解释怎么读；明确它不替代团队建设与日常沟通、也不是规则大全。

适用：② 远程上下级破冰（异步为主的团队）——用文档补足见不到面带来的期望模糊，含真实企业范例结构。

领导干部谈心谈话制度：四类内容 + 三必谈 + 结果运用闭环

谈心谈话制度上下级一手

权威一手把「上下级常态沟通」制度化，并直指失效症状：谈心谈话寡淡无味、有名无实、有头无尾——谈心未能交心，谈话成了例行公事；原因是内容设定不够清晰明确难以触碰实质性问题、对象沟通缺乏充分了解难以形成心与心交流、标准评价重形式过程轻结果运用。三条解法：①强化政治责任与认识——党内法规明确「坚持谈心谈话制度」，要求「领导干部要带头谈，也要接受党员、干部约谈」。②细化内容形式，分四类：日常工作类（了解掌握日常思想与工作状态、及时听取反馈意见建议、做好思想沟通与工作指导；不受形式所限、无需刻意、随时进行、融入日常）；关心关爱类（了解掌握工作生活中的矛盾困难变故、倾听心声诉求、给予心理疏导安慰，并在政策条件许可范围内尽力解决；由情入理、由浅入深，把解决思想问题与解决实际问题统一起来）；职务任免类（进退留转时交流思想、交换意见，向在职干部提明确要求，对离退休干部作客观评价并请其留意见；正式严肃、有理有据，既坦诚相见又有原则坚守）；警示督促类（抓住重要节日、重要任务部署、重要会议召开等节点作提示提醒，对落实不力、班子不团结、群众满意度不高及苗头性倾向性问题，既指出问题批评教育，又督促整改，把问题解决在萌芽中）。个体性问题用个别谈、普遍性问题用集体谈；对流动、困难、年老体弱与离退休党员可用电话、微信、邮件、上门访谈等形式。③健全机制——「三必谈」：党委（党组）主要负责同志与班子成员必谈、班子成员相互之间必谈、班子成员与分管部门单位主要负责同志必谈；按管理权限与职责范围分层级确定对象；流程含谈前调查准备、谈中情况记录、谈后信息汇总、解决时的主要措施；监督保障（需保密的保密存档、需整改的调查核实并适当方式反馈、跟踪检查问效）；结果运用纳入部门单位年度党建目标管理责任考核，切实解决「谈话热、整改冷」，防止变成作秀。

怎么做
把上下级谈话按四类（日常工作/关心关爱/职务任免/警示督促）分别定内容与尺度；落实三必谈；按管理权限分层级定对象清单；四步流程（谈前准备→谈中记录→谈后汇总→措施落实）；保密存档 + 跟踪问效 + 纳入年度考核，避免「谈话热整改冷」。

适用：② 上下级常态化沟通制度（一手 · 学习时报/人民网党建）——中国组织语境下最成体系的「领导↔员工谈话」框架，可直译为企业 1:1 分类机制。

谈心谈话「四多四少」诊断 + 谈前/谈中/谈后三段法

谈话失效自检上下级一手

一线主责者（国家卫生健康委直属机关党委常务副书记）署名复盘的四类失效，即「四多四少」：会前突击被动式谈的多、平时常态化主动谈的少；上对下谈的多、下对上谈的少；委员与委员之间谈成绩的多、有针对性谈问题的少；大而化之谈工作的多、认认真真剖析思想的少。对应做法：①领导干部带头示范——落实「领导干部要带头谈」，一般做到三必谈；领导干部要主动联系群众、主动找分管范围内的一般干部谈话，也要接受党员干部约谈（这是改进作风、做好群众工作的基本要求）。②见人见事见思想——班子成员之间要带着问题谈：既主动亮明自身问题，又诚恳指出对方问题，相互交换对班子主要问题的看法并探讨解决建议；领导与下级谈话要「出以公心，以同志间平等的身份谈」，有什么问题提什么问题、是什么问题摆什么问题，敞开心扉、推心置腹；善用重要节点——机构改革中及时排解思想顾虑、引导正确对待进退留转；干部选任时听其言观其行，精准掌握思想工作与心态；攻坚任务中旗帜鲜明为一线加油鼓劲，帮助解决生活工作实际困难，在政治上激励、工作上支持、待遇上保障、心理上关怀。③谈话前精心准备——把握主题找准问题（因人、因事、因时，精准发力有的放矢），尽可能了解对象的个人经历、家庭情况、性格爱好，以把握谈话内容的尺度；设定好话题并预判难题（对过程发展态势及可能出现的问题、意见、分歧、突发事件预估到位，因势利导掌握节奏）。④谈话中积极应对——以党性共勉、以本色相见、以坦荡为怀；用活态度、礼仪、言语三方面的感染力，创造良好「心境」；带着感情谈，以真心对真心、用真情换真情。⑤谈后闭环——对听到的意见、谈到的问题本着「有则改之、无则加勉」，事后拿出具体整改方案，把根源挖深、措施找准，跟踪问效、巩固成果，形成谈心谈话的「闭合回路」。

怎么做
先用「四多四少」自检现状；带头谈 + 接受约谈（双向、破上对下单通道）；谈前做对象功课（经历/家庭/性格）并预判分歧与突发；谈中控节奏、用态度礼仪言语造心境；谈后出具体整改方案 + 跟踪问效形成闭合回路。

适用：② 上下级谈话质量诊断与三段法（一手 · 当事人署名）——尤其修正「只有上对下、只谈成绩」两个通病，适配企业管理者 1:1 复盘。

履新干部「第一课」：个别谈心谈话 + 集体谈话会 + 试用期考核闭环

履新第一课上下级一手

官方一手做法（陕西省总工会党组）：把新任职干部上岗前的「破冰」做成制度化的「第一课」，严格按《党政领导干部选拔任用工作条例》落实任职谈话制度，通过政策理论考试、个别谈心谈话、集体谈话等方式加强任职前教育。两段结构：①先由党组主要领导和党组成员对新任职干部逐一进行个别谈话——帮助任职干部找问题找差距，结合存在不足谈改进谈落实，推心置腹、坦诚相见；②再开集体谈话会——任职干部认真汇报思想，厅级领导逐一点评、提出工作要求、寄予殷切希望，为履新干部上好「第一课」。三条内容主线：要求干部认真查摆问题；要求切实转变作风（强化「作为」意识、提高「能为」本领、找准「善为」路径，把工作干成事业、干到职工群众心坎上，身先士卒抓工作、以身作则抓落实，与广大干部职工想在一起、干在一起）；要求筑牢思想防线（纪检监察派驻纪检组全程参加指导并对新任职干部提出具体要求：坚守政治原则、强化自我约束、加强理论学习、严格履行「一岗双责」，守住纪律底线、不越法律红线、守好道德防线）。配套闭环：试用期满后还将采取政治理论考试、谈话考核、书面考核等方式，结合日常考核成绩对新任用干部进行试用期考核。

怎么做
上岗前设「个别谈话 → 集体谈话会」两段：个别谈话聚焦找差距 + 改进承诺，集体会做思想汇报 + 上级逐一点评 + 明确工作要求；纪律/合规部门参与并提具体约束；试用期满做考核闭环（考试 + 谈话 + 书面 + 日常成绩）。

领导人员三类谈话制度化：任前 / 提醒 / 诫勉（含 15 工作日整改）

三类正式谈话上下级一手

大型央企（中国电子）把「上级对领导人员的谈话」写成《党员领导人员廉洁谈话办法》（六章二十一条），对主体、对象、方式、程序与权限作出规定，突出因人制宜、抓早抓小，把约谈工作制度化。三类谈话：①任职上岗前教育谈话——对党委（党组）、董事会和经营班子新任用的党员领导人员，在上岗前进行廉洁从业纪律法规教育，提醒在新岗位上既要奋发有为又要廉洁自律，打好「不为乱为」预防针。②发现苗头时提醒谈话——对象包括：工作不在状态、群众有议论或微词但没有明确具体问题的；在履新升迁、出国、就医、子女入学、婚丧嫁娶、庆生过节等方面活动频繁引起关注的；任期内从事工程建设、重组并购、物资采购、物业经营、产品销售等风险度较高工作且需要提醒的；以及群众意见较多、满意度较低的企业及部门主要负责人；方式是谈心式、提醒式、预警式，通过多「咬耳朵」、勤「扯袖子」，早发现风险、早处理问题，不使小事变大、苗头成案。③存在问题时诫勉谈话——对在政治、思想、工作、作风、纪律和廉洁从业等方面存在问题者进行诫勉，通过教育规诫与监督管理指出问题实质、帮助分析原因、提出改正要求；对网络舆情、群众信访和检举控告反映的问题也可用书面形式函询；谈话对象必须在 15 个工作日内对存在的问题制定整改措施，主谈部门及有关部门还应安排专人跟踪落实纠错情况。主体与覆盖：实施主体为各级纪检监察和组织人事部门，一般由纪委书记（纪检组长）或分管组织人事的公司领导主谈，必要时由党委（党组）书记、董事长、总经理直接主谈；集团各级企业中的非党员领导人员及市场化聘用的职业经理人，按干部管理权限参照本办法开展。

怎么做
把上下级正式谈话拆三类（任前教育 / 苗头提醒 / 问题诫勉）并写明各自触发情形清单；提醒谈话锁定高风险岗位与异常活动信号；诫勉后强制 15 个工作日内出整改措施 + 专人跟踪；明确主谈人层级（必要时一号位直接谈）；非党员与职业经理人参照执行以保覆盖。
