高管过渡·董事会/团队/关键利益方信任建设 + 关系转移

高管上任过渡高管间二手

新高管前 90 天「听优于决、学优于指」。三大支柱：①理解业务语境/盘团队强弱项/找速赢建信誉不透支；②与董事会、团队、关键利益方显式对齐期望。信任不是假设——靠一致行为、可靠沟通、持续胜任累积。最被低估的是「关系转移」：离任→继任须结构化移交关键客户/战略伙伴/大供应商/长期董事会关系（这些不在文档里），用结构化交接会+离任者/董事促成的引介电话+外部关系简报平滑过渡，保连续性与战略势能。坑：过快+少听、带预设议程、轻视文化细微导致抗阻。高管教练 ROI：个人+70%/团队+50%/组织+48%；87% 认为高管教练高 ROI。

怎么做
新高管 90 天「听优于决」；做董事会/团队/利益方的关系转移（结构化交接会+引介电话+外部关系简报）；把教练/同侪顾问当正式过渡支持，勿带预设议程。
🔗 skillpanel.com/it?p=4896128
适用：③ 新任高管/CEO 上任过渡——董事会/团队/关键方信任靠「关系转移」（结构化交接+引介）而非假设，配高管教练/同侪网络补关系工作（高管间，非游戏）。

高管入职·「语境先于内容」+ 「意愿联盟」

高管入职高管间二手

高管入职常被当形式（几场介绍+战略概览+系统权限）。真正差异在深度、结构、人的洞察。4 支柱：①语境先于内容——不只公司数据，而是「决策为何这样定/谁真在做主/政治与文化地形」，把正式数据与非正式洞察（董事会视角/利益方期待/历史教训）配对，让高管从清晰而非揣测起步；②建关系而非只报告——识别「意愿联盟」（share 愿景、能跟你快跑的人），结构化利益方引介而非日历上的会；③授权与指标显式化——董事会前三大优先项/12 月「成功」长啥样/须做的取舍；④文化×战略同频——读文化（如何协作/如何被奖励/压力下如何反应）再引入自己的 tone。90 天分段：D1-30 学且听 / D31-60 对齐并规划 / D61-90 行动并沟通。董事会须持续 check-in，过早「退后」恰是新手最需指引时。

怎么做
高管入职用「语境先于内容」（决策史/权力地形/文化）+ 建「意愿联盟」+ 显式授权指标；90 天 D1-30 听 / D31-60 对齐 / D61-90 行动；董事会持续 check-in 不早退。
🔗 www.lucasrec.com/onboarding-new-executives/
适用：③ 新任高管/exec 入职——「语境先于内容」+「意愿联盟」+ 显式授权指标，90 天分段，董事会持续护航（高管间，避免幼稚破冰）。

新任 CEO 90 天路线图·倾听之旅 + 早期胜仗

CEO上任高管间二手

前 90 天不对称：早期信誉复利多年，早期失误被整个任期翻旧账。三阶段每段都要「交付物」：上任前——拿书面授权（成果/约束/埋的雷）、读运营记录、画利益方地图；D1-30 听与诊断（与每位高管/关键董事/客户与一线抽样结构化 1:1、摸清真实财务、诚实地评估高管团队、公开「我在学而非改」姿态、忍住不宣布）；D31-60 对齐与决断（私下与董事会压测观点、做 2-3 个不能等的人事决策、重置运营节律与决策权、书面敲定 3 年授权）；D61-90 行动与交付（全员诚实地讲变与不变、启动带 owner/资源/日期的首批战略动作、交付一个组织「感得到」的早期胜仗——解一个大家学会绕开的久拖决策、比任何 town hall 都灵）。坑：过度宣布+诊断不足（像傲慢，常被撤回）。

怎么做
新任 CEO 90 天「听优于决」；上任前锁书面授权+利益方地图；D1-30 倾听之旅产「诚实诊断」向上交付；D31-60 私下与董事会压测+做不能等的人事；D61-90 解一个久拖决策作「早期胜仗」。
🔗 www.jrgpartners.com/first-90-days-onboarding-roadmap-ceo/
适用：③ 新任 CEO 上任——90 天路线图（倾听之旅+早期胜仗），上任前锁书面授权，D1-30 忍住不宣布、每段交付artifact（高管间，商务化）。

CEO 接班·董事会主导的上任护航 + 18 个月融合期

CEO接班治理高管间二手

董事会对上任 CEO 的支持常被「模糊且不足」，18 个月内失败率高，故最佳过渡期应长达 18 个月（而非仅 90 天 onboarding）。上任期（前 90 天蜜月）：与执行团队/董事/关键领导/利益方 1:1 或小组会建有意义连接、建信任、点燃协作；CEO 不是房间里最能干的人，须多问多听、记下观点但「别表态」；高管团队有人担心被换、已在别处面试，CEO 须迅速结坚固联盟、认管理团队能力。融合期（90 天后）：复盘管理团队与缺口、修订战略、与关键管理团队对齐新计划、亲自讲计划+让领导讲细节、用 KPI+监控框架、与董事会汇报拿 sign-off、短程胜仗+奖励。CHRO 是过渡团队核心顾问；planned succession 时让离任 CEO 做知识移交（运营风格/对高管期望/董事会与关键关系——投资人/客户/监管）。

怎么做
董事会主导 CEO 上任护航，过渡期拉长到 18 个月；前 90 天 1:1/小组会建连接忍住不表态；90 天后与董事会 sign-off + KPI 监控；CHRO 任过渡顾问，planned succession 让离任 CEO 做知识移交。
🔗 www.lansdowneboardintelligence.com/selecting-your-next-leader-ceo-succession-tips-part-2
适用：③ 董事会/治理层主导 CEO 接班——过渡期 18 个月（非仅 90 天），前 90 天忍住不表态建连接，CHRO 任过渡顾问、离任 CEO 做知识移交（高管间/治理层，商务化）。

新经理首周「诊断式」团队破冰模板（远程团队）

新经理上手上下级二手

新经理首周别搞「轻量破冰游戏」——讲个人趣事让房间变冷。有效做法是用 30 分钟团队 kickoff + 每人 20 分钟 1:1 + 一份 15 分钟书面预提问，先让「工作行为可见」而非「感情可见」。5 个诊断问：别人怎么打断你、什么让你有防御心、怎样的周算「坏周」、你不愿开口求助的支持、你眼里的「高效会议」长啥样。30-60-90 天：D1-30 诊断（kickoff+工作风格+沟通 retro），D31- 60 对齐（响应时效标准/哪些决策需实时对话/如何升级阻塞），D61-90 重复最小有用仪式（周 retro+月度跨职能 pairing+轻量 check-in）。判断标准：团队能不靠你翻译就协调，才说明模板落地（不是「大家变熟」）。

怎么做
首周只做 3 个触点：团队 kickoff + 工作风格 session + 沟通 retro；用「如何被中断/坏周什么样/不愿求助什么」等诊断问替代个人趣事；30-60-90 从诊断收窄到规则再到重复仪式。
🔗 sirjohnnymai.com/blog/new-manager-team-building-activity-template-for-remote-startups
适用：② 新经理/新主管上任首周团队融合——用「诊断式」轻量结构（kickoff+1:1+书面预提问）替代破冰游戏，30-60-90 从诊断收窄到规则到重复仪式（远程团队）。

远程团队「非尴尬」破冰与信任建设（buddy 制 + 1:1 问法）

远程信任上下级二手

远程团队建设 ≠ 幼稚游戏。三件套：①入职上下文写作——把公司史/使命愿景/沟通会议规则/业务背景/6-18 月里程碑写成 context 文档，让新人「有语境」；②「我们为什么招你」信——告诉新人你被看重的点，建立 rapport 比什么都快；③定期 1:1——问工作偏好与期待（而非私人生活）。避坑：别再用「周末怎样」这类磨损的老破冰。新人 1:1 好问题：最兴奋什么/前两周最挫败什么/哪里不清/想被辅导什么/明年最自豪的一件事是什么。另配 buddy 制（51% 远程公司这么做）+ 非工作闲聊频道（watercooler/pets）补情感信任。

怎么做
用「context 文档 + 我们为啥招你信 + 结构化 1:1」三件套替代破冰游戏；buddy 制 + 非工作频道补情感信任；1:1 问工作偏好而非私人生活。
🔗 knowyourteam.com/blog/2020/05/10/virtual-team-building-how-to-build-trust-in-a-remote-team/
适用：② 远程/混合团队管理者——用 context 文档、招聘信、结构化 1:1 与 buddy 制建 affective trust，避开「周末怎样」式磨损破冰（主管主导）。

跨部门协作工作坊·拆筒仓的 7 种结构化格式

跨部门破筒仓上下级二手

筒仓成本不只是沟通差：认知割裂、重复劳动、决策卡审批链、互相甩锅、创新在学科交界处被堵。工作坊是「专门空间」解法。有效设计：①定义共享且真正跨部门的「问题」而非「市场部要线索」；②策展多元参与（决策者+一线+技术+创意），代表即合法性；③建立共同 ground（「一天 life」练习/流程映射显依赖）；④可视化端到端（客户旅程图/服务蓝图，各部门贡献自己那块）；⑤视角代入（角色扮演/从他部门视角评点）；⑥焦点回到「我们」而非「我部门」；⑦跨职能行动小组（清晰 owner+截止）。关键：单次活动会 fade，须配套结构化反思 + 2-4 周后跟进 + 持续沟通框架才长效；领导 visible 参与显著降低抗拒。

怎么做
别办一次性「团建」式 workshop；按「共享问题→多元参与→共同语言→可视化端到端→跨职能行动组(owner+截止)」设计；配套复盘 + 跟进触点防 fade；领导 visible 参与降抗拒。
🔗 www.noodleresearch.com/field-notes/bridging-silos-how-workshops-foster-cross-functional-collaboration
适用：② 管理者/PM 主导跨部门拆筒仓——用 7 类结构化 workshop 格式（含角色扮演/端到端可视化/跨职能行动组）替代一次性活动，配套复盘与跟进防失效。

组建跨职能团队· facilitator + 团队宪章 + 2 小时 kickoff

跨职能团队组建上下级二手

跨职能团队成功 7 步：①定使命与「成功长啥样」；②盘依赖与决策权（冲突时「辩论-决定-承诺」即使不同意）；③选 facilitator 而非 dictator——仆人式领导，清路障/护团队/守宪章，可由 PM/PMO/轮值担任；④定「单一事实源」技术栈（任务 Asana/Jira、沟通 Slack/Teams、文档 Notion/Confluence），工具之争是内耗；⑤kickoff 至少 2 小时（自我介绍「你希望从这项目学什么」+ 使命 Why/What + 共创团队宪章 + 定首 sprint）+ ⑥建立反馈节律（每 1-2 周 retro：保持/停止/开始）；⑦持续 momentum。坑：忽略部门政治（须先获每位成员直属上级正式 buy-in 写进绩效目标）、公开庆祝小胜、护团队不被「swoop and poop」（空降高层随意反馈后飞走）。

怎么做
跨职能团队先定使命/决策权/单一事实源技术栈；kickoff ≥2h 含共创团队宪章；配 facilitator（仆人式）+ 每 1-2 周 retro；先拿直属上级 buy-in、公开庆祝小胜、护团队免受空降反馈。
🔗 eathealthy365.com/steps-to-create-a-cross-functional-team
适用：② 管理者/PM 组建跨职能团队——facilitator（非 boss）+ 团队宪章 + ≥2h kickoff + 周/双周 retro 节奏，先锁直属上级 buy-in 防部门政治拆台。

新人首次 1:1 向上问的 14 个问题（下属→主管）

向上沟通上下级二手

首次 〓1:1（无论新人入职、转团队、还是换了新主管）是建立信任最关键的一场。别只让主管主导，主动问对问题价值更高。14 问：你最近怎样 / 你的管理风格 / 你偏好怎么沟通 / 偏好如何给与收反馈 / 你的职业目标 / 我能怎么让你好做 / 你对我的期待 / 你怎样评估我的表现 / 我能向谁学 / 你看到我什么成长机会 / 哪些书/播客助你成长 / 你给我的建议 / 下月/季/年团队目标 / 下场 1:1 我该定什么目标。数据：85.2% 的 1:1 在远程进行；1:1 提升生产力、敬业度、降低 burnout。开场轻量友好定调，中段问管理风格与期望建立对齐。

怎么做
新人/换主管首场 1:1 主动发问而非被动听；用「你的管理风格/你怎样评估我/我对你的期待/我能怎么让你好做」等 14 问建立对齐；开场轻量、中段挖期望。
🔗 www.deel.com/blog/one-on-one-questions-to-ask-your-manager/
适用：② 下属→新主管/换新团队首次 1:1——用 14 个向上问句（管理风格/评估标准/期待/怎样让主管好做）主动建信任与对齐（上下级，下属视角）。
