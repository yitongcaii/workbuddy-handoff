我们花费的努力

How it's built
  • 自动化轮询采集：每 6 小时从 6 主题池定点轮询一个主题，多源 WebSearch 定向 ②/③ 一手 / 二手源，刻意不搜平级内容。
  • 六维评估筛选：相关度 / 权威性 / 时效性 / 去重度 / 可落地 / 关系适配度各 1–5 分，任一 <3 淘汰，跨档从严。
  • 历史去重：比对 index.json（URL、标题归一化、摘要重合），重复则留更全更权威版，累计去重删 M 条。
  • 剔除平级 / 朋友向：关系档含 peer 的条目在本步直接判排除，零外写、零进库——这是用户明确硬约束。
  • 卡片墙渲染：紫青渐变、白卡圆角 18px、顶部 4px 强调色、胶囊分类标签，每张卡含 emoji + 价值描述 + 一手二手标签 + 来源链接 +「怎么做」折叠 + 适用备注 + 页脚。
  • 三端同步部署：GitHub Pages（长期托管线上卡片墙）+ 乐享团队文件夹（HTML 文件原样 file 上传，保留 CSS 样式）+ Obsidian 知识采集库（仅 markdown 索引 + 链接，不存 HTML 副本）。
  • 乐享通道攻坚：连接器状态栏滞后显示 disconnected，实测 MCP 仍可用；踩通「file 上传更新场景」扩展名对齐坑（name 带 .html 后缀），确保原样样式落团队空间「待清洗素材」。
