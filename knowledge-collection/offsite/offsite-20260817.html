高管 Offsite 议程模板 + 90 天落地（3 优先级 + 首检<14天 + 沟通计划）

议程模板高管间二手

高管 offsite 真正产出是离场后的 90 天，不是开两天会。议程必备五块：开场定 stakes、数据/诊断、围绕一个主结果的决策逼迫、把决策变 owner+deadline 的激活块、收尾承诺轮（当场指派 owner 与首检）。离场前把第一次 check-in 锁进日历（带 owner+格式），14 天内必须发生否则 momentum 死；之后每两周一次直到 90 天再转月度。三个优先级原则（不是 7 或 12）：选 3 个并明确「为它们停掉什么」。沟通计划最易被跳过——组织其余人都在看是否真有改变，不定下来他们会默认 offsite 是浪费；离场前先起草「定了什么/会变什么/30 天内看到什么」。承诺无后果=愿望，提前约定一次/两次/三次未达成的处理；当着同侪承诺比私下更易守住。

怎么做
议程五块（stakes→诊断→决策逼迫→激活owner→收尾承诺）；离场前锁首检（<14天,owner+格式）；每两周 check-in 到 90 天转月度；只留 3 个优先级并写明停掉什么；离场前起草沟通计划（定了/会变/30天可见）；提前约定未达成后果。
🔗 https://consultclarity.org/post/executive-offsite-agenda-templates
适用：③ 高管/领导团队 offsite，「议程模板 + 90 天落地节奏 + 3 优先级 + 沟通计划 + 后果约定」是可迁移硬框架。🔍 差异化：区别于卡片（consultclarity follow-through 仅讲 90 天六检查点/decision log）——本卡从「议程模板本身 + 优先级纪律 + 沟通计划 + 后果」切入，补会前到离场完整闭环。

高管 Offsite 外部引导师选聘（何时外部/预访谈/敢挑战CEO/费用区间）

引导师选聘高管间二手

何时请外部引导师：内容敏感、团队动态复杂、决策高价值时，leader 无法既驱动流程又自由参与，必须外请。筛选六问：谁会被访谈、机密主题如何处理、最强者主导时引导师怎么办、交付物具体是什么（决策声明/owner/决策权/未决问题/30天节奏）、按层级/语言/沟通规范怎么调、能否说清自己不适用场景（能说局限才可信）。费用全景：个人/精品从业者两天 $5k–25k（含预访谈+设计+引导+48h 纪要）；品牌方法论精品 $15k–80k；咨询 comprehensive $75k–150k+；另加场地 $750–950/人/晚。警示：用 day rate 比价是错的（无预访谈无产出者回报更低）；用满意度打分衡量成功是错的（离场爽但无决策=失败）；最该问的是「我主导对话时你会当众怼我吗」。

怎么做
敏感/复杂/高价值议题必外请引导师；筛选六问（访谈/机密/主导者处理/交付物/层级适配/自陈局限）；费用按 tier 预算（$5k–150k+）；用「能否当众挑战 CEO」而非 day rate 或满意度评分做最终判据。
🔗 https://www.consultclarity.org/post/executive-team-offsite-facilitators-asia
适用：③ 高管团队 offsite 选聘外部引导师，「何时外请 + 六问筛选 + 费用全景 + 挑战CEO判据」是可迁移采购框架。🔍 差异化：区别于卡片（sorenkaplan/theoffsiteco 讲如何 run offsite）——本卡专讲「引导师选聘」这一独立决策，补采购侧。

高管 Offsite 落地四件套（责任分配表 + 问责看板 + 监控调整 + 评分卡评估）

落地跟进高管间二手

offsite 的价值在会后不在会上。四步把洞察变结果：① 责任分配——每个 action item 指定唯一 owner（按优势+现有负荷），给 due date，形成 accountability 路线图；② 建立问责——定期 check-in/团队会复盘，建共享 dashboard 追踪关键举措进度，透明即对齐；③ 监控调整——举措推进中重估时间线/重配资源/必要时 pivot，把 offsite 结论当活文档；④ 评估——用评分卡对照目标（定量+定性），收集参与者 survey/1:1 反馈，区分 met/unmet。把「目标-结果」表可视化：目标 | 结果 | 达成与否，让 ROI 可证。

怎么做
会后四步落地：责任分配表（唯一 owner+due date）→ 共享 dashboard+定期 check-in 建问责 → 重估时间线/资源/pivot 监控调整 → 评分卡（目标|结果|达成）对照+参与者反馈评估。
🔗 https://www.sorenkaplan.com/leading-executive-team-offsites-for-business-strategy
适用：③ 高管/领导团队战略 offsite，「责任分配 + 问责看板 + 监控调整 + 评分卡评估」是可迁移落地四件套。🔍 差异化：区别于卡片（consultclarity 90天节奏/jeremyhaynes 30/60/90）——本卡从「责任分配表+问责看板+评分卡评估」结构化落地视角切入，补度量与可视化。

管理层 Offsite 定公司级 OKR 再下钻团队 cascade（领导力变更期透明对齐）

战略对齐高管间二手

领导力变更期最怕目标失焦。用 cascade OKR 把新管理愿景翻译成全员可执行的节奏：① 领导层先定公司级 OKR（3–5 个目标，雄心但可达）；② 部门 head 主动认领「我的团队能独特贡献什么」（是对话不是下派）；③ CFO/HR 等把目标连到公司级（如成本效率支援增长）；④ 在 OKR 系统显式标注连接，让横向可见（避免信息孤岛）；⑤ 为不同层级（高管/中层/IC）配不同 dashboard 视图。透明是良药：当大家看得见「我的目标如何支撑公司目标」，猜疑变 ownership。新领导可快速判断战略是否真下沉——某目标只有 1–2 个团队支撑就是红旗。

怎么做
领导力变更期用 cascade OKR：领导层先定 3–5 公司级 OKR → 部门 head 对话式认领贡献 → 显式标注目标连接（横向可见）→ 分层 dashboard（高管/中层/IC 不同视图）→ 用「支撑团队数」识别战略红旗。
🔗 https://perdoo.com/resources/blog/creating-transparency-in-times-of-leadership-change-using-okrs-to-align-new-management-vision
适用：③ 高管/新领导团队在变更期用 offsite 定调并 cascade OKR，「公司级先定→部门认领→显式连接→分层视图」是可迁移对齐框架。🔍 差异化：区别于卡片（selena-secor 全员共创太慢→改 leadership 先定再下钻 case）——本卡从「cascade 透明对齐 + 分层 dashboard + 红旗识别」方法论切入，补治理视角。

远程团队季度 Offsite 定 OKR + 双周 1:1 追踪（信任自主不 micromanage）

远程团队上下级二手

远程团队更难但不必 micromanage。某 CTO 的打法：每季度第一周把团队（CTO+产品+内容 head）拉 offsite，先用便利贴列出所有人想完成的，再收敛成可行季度 OKR，口头约定后文档化，双周 1:1 追踪风险/推进、季末复盘再重置。决策权分层清晰：CEO 对财务健康负责，CTO 对战略负责，激活层（战略→OKR→执行）落在 CTO 与下级的接口。信任来自「季度初定 OKR + 双周 1:1 无惊喜」：给足自主，风险在双周谈，需要时才介入。manager 不靠盯 commit 管人，而靠节奏与透明。

怎么做
远程团队季度 offsite 定 OKR（便利贴列全员想做→收敛可行→口头约定→文档化）；双周 1:1 追踪风险/推进、季末复盘重置；决策权分层（CEO财务/高管战略/激活层落接口）；用节奏+透明替代 micromanage。
🔗 https://distantjob.com/blog/podcasts/keys-to-successful-remote-work-strategy-mike-soldan
适用：② 远程/分布式团队 manager 主导的季度 offsite，「便利贴收敛 OKR + 双周 1:1 追踪 + 决策权分层 + 信任自主」是可迁移管理框架。🔍 差异化：区别于卡片（dropbox 分布式 offsite 加速信任/sumup 新组建团队）——本卡聚焦「远程团队 OKR 节奏 + 双周 1:1 不 micromanage」的管理机制，补远程治理。

季度团队 Offsite 议程模板（经营复盘 + 战略 + 连接 + 承诺收尾）

团队议程上下级二手

manager 主导的一日季度团队 offsite 可直接套的模板：目标块（业务结果/团队结果/需决策/预读）→ 上午（开场 check-in 一个词+客户引言 / 季度复盘 metrics walk-through 静默评论 / 战略讨论比对三个增长赌注 / 决策 checkpoint 用 impact-confidence-effort 排序）→ 下午（规划工作坊定 owner+里程碑+风险 / ways-of-working retro 用 start-stop-continue / 连接活动配对讲「最好的经理」故事 / 承诺收尾每人说一个周五交付）。含真实填好的例子（Growth Marketing 团队 Q4 获客赌注）。要点：会前定 2–3 结果并指 owner；breakout 给单一 prompt+5 分钟 report-out；把酒精放成果之后；离场前 capture 决策+owner+deadline 进一文档。

怎么做
manager 季度团队 offsite 套模板：目标块（业务/团队/决策/预读）→ 上午复盘+战略+决策排序 → 下午规划(owner/里程碑/风险)+retro(start-stop-continue)+连接故事+承诺收尾；会前定 2–3 结果指 owner；breakout 单一 prompt+5 分钟 report；离场前 capture 决策进一文档。
🔗 https://hogonext.com/templates/quarterly-team-offsite-agenda
适用：② 部门/业务团队 manager 主导的季度 offsite，「经营复盘+战略+连接+承诺收尾 一日模板 + 真实填例」是可迁移实操。🔍 差异化：区别于卡片（stonehouse 一日 team offsite 偏餐饮/散步 hospitality/venue 视角）——本卡是带真实填例的「业务+复盘+retro+承诺」管理模板，补可执行结构。
