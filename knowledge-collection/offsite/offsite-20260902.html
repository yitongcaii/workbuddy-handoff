高管团队冲突对话结构化（CEO不当Secret Therapist/把框/澄清事实/分派责任/5步法）

高管冲突高管间二手

高管团队内冲突（强个性/高压力/利益竞争）是常态。常见陷阱：CEO 滑入「秘密治疗师」角色——听长故事、安抚、解释，最终扛下全组织情绪负荷，责任从当事方转移到自己，冲突变慢性病。正确姿态：lead, don't therapize。CEO 的角色是「Hold the Frame（定框）」：明确谁在场/为何开/开多久/怎么互动；把对话从「他难搞」转向「在X情境，Y发生，后果Z」；分派责任（每人own自己的行为/沟通/对解决方案的贡献）。三人/团队对话5步法：①定框+规则（目标=可协作基础，轮流发言、不人身攻击、聚焦业务）；②A 陈述（3要点+具体情境+对团队/项目影响，B 记录）；③B 同权陈述；④共同澄清（重叠在哪/最强摩擦在哪/任务层vs关系层）；⑤达成约定（明确规则+纪录+6周后复盘）。核心：冲突处理是领导力工作，桌上每人都是主动塑造者，不是被调和对象。

怎么做
CEO不当秘密治疗师(不扛全组织情绪);Hold the Frame定框(谁在场/为何开/开多久/怎么互动);把对话从人转向情境(在X,Y发生,Z后果);分派责任(每人own行为/沟通/贡献);三人对话5步(定框规则→A陈述3要点+情境+影响→B同权→澄清重叠/摩擦/任务层vs关系层→达成约定+纪录+6周复盘);冲突=领导力工作非被调和。
🔗 Karsten Noack·领导团队冲突对话(高管教练二手)
适用：③ 高管团队内部冲突/分歧的务虚处理，「CEO不当秘密治疗师+Hold the Frame+5步法」是可迁移执行结构。🔍 区别于卡片（普通冲突调解/中层难对话）；本卡聚焦「高管层（含CEO本人涉入）冲突的结构化对话」，补「高管冲突治理」这一硬缺口。

高管间冲突分级干预（CEO/董事会/HR/外部调解人角色·外部调解ROI $1800 vs 离职$25万）

高管冲突高管间二手

高管成员冲突按严重度选干预方：两个直接下属冲突→CEO或外部调解；涉及CEO→董事会主席或外部调解；高危/法律敏感→仅外部调解；早期低烈度→资深HR。关键结构决策：联合会话前的「一对一诊断」是全流程最重要的一步。若你本人是冲突一方：先做诚实自审（是否只跟第三方讲过、是否假设了对方意图、行为升级还是降级了张力），再用非指责式开场（「我注意到咱们之间有张力，想先听你的视角」）。升级判据：影响跨职能执行且直接解决失败→找CEO；你是CEO或涉治理/受托责任→找董事会；有记录在案的行为事件→找HR；内部升级失败或权力结构使内部引导不妥→外部调解人。ROI：外部调解人$300/时×6场=$1800，而SHRM 研究一名高管离职成本=年薪40%-200%（$25万-$50万+）；早期专业干预ROI极高。Gottman 研究：受损关系需5:1正/负互动比才稳。

怎么做
按严重度选干预方(两下属冲突→CEO/外部;涉CEO→董事会主席/外部;高危法律→仅外部;早期→资深HR);联合会话前必做一对一诊断;自涉冲突先诚实自审+非指责开场;升级判据(跨职能失败→CEO/涉治理→董事会/行为事件→HR/内部失败→外部);外部调解$1800 vs 离职$25万 ROI极高;受损关系需5:1正负面比。
🔗 George Dupont Leadership·高管成员冲突处理(高管教练二手)
适用：③ 高管层（C-suite/直接下属）冲突的分级干预与升级路径，「谁该介入+一对一诊断+外部调解ROI」是可迁移治理。🔍 区别于卡片（CEO秘密治疗师/karstennoack）；本卡补「升级判据与外部调解成本论证」这一决策层缺口（给CEO/CHRO的预算弹药）。

从 Offsite 到 operating model（决策权 RACI/RAPID·一层决策日历栈·单向门/双向门）

决策机制高管间二手

offsite 的产出要落到 operating model 才不回弹。决策权框架解决「谁决定」：RACI（执行/交接，Responsible/Accountable/Consulted/Informed）用于跨职能执行；RAPID（Recommend/Agree/Perform/Input/Decide）用于离散决策，关键是单一 Decider + 收窄的 Agree（仅合规/存在风险用 veto），publish RAPID map 给常发决策类型免重复谈判。设计规则：一个 D（顶层模糊=下层拖延）；少 A；紧 R（推荐者给选项+数据+权衡非鼓吹）；time box（Input/Agree 设截止+默认推进）；决策日志（决策/owner/理由/阈值/复查日）。决策分类：单向门（难逆→更高门槛+更广咨询+pre-mortem+董事会可见）vs 双向门（可逆→本地 D+轻 RAPID）。领导节奏（日历即战略）：年度方向重置(2-3天)→半年度架构/风险→季度组合评审→月度运营→双周执行→持续决策日志+指标流。

怎么做
offsite产出落operating model才不回弹;RACI(执行交接)vs RAPID(离散决策,单一Decider+收窄Agree+publish map);设计规则(一个D/少A/紧R/time box/决策日志);决策分类(单向门高门槛+pre-mortem+董事会可见/双向门本地D轻RAPID);领导日历栈(年度→半年度→季度→月度→双周→持续决策日志)。
🔗 Umbrex·从Offsite到Operating Model(顾问一手/二手)
适用：③ 高管 offsite 后把战略转化为决策机制与节奏，「RACI/RAPID+单向门/双向门+领导日历栈」是可迁移 operating model。🔍 区别于卡片（90天跟进节奏/决策权框架RAPID单篇）；本卡补「offsite→operating model整体翻译+日历即战略」这一系统层缺口。

领导力 Offsite 前摄心理安全（4阶段·pre-survey 显隐忧·会中建安全动作）

心理安全高管间二手

offsite 大部分是在「建」心理安全而非「享其果」。前置3件事：①co-creation 预对齐（共拟目标/成功标准/是否守时开场收场，会前拿到全员buy-in）；②评估心理安全——用 Timothy Clark 四阶段模型：归属安全(Inclusion)→学习者安全(Learner)→贡献安全(Contributor)→挑战安全(Challenger，敢质疑权威/提重大变更)。多数CEO自认团队已在挑战安全，但直接问员工常发现相反；pre-survey 显露出差距可重置领导预期；③会中主动动作：确认并邀新人讲「怎么帮你成功」、明示期望、确保信息对称、直接问「公司能做什么让你够安全去升级」。框架可下钻到季度/月度/周会。心理安全不隔夜变，但预规划能照亮流程与文化缺口。

怎么做
offsite在建心理安全非享其果;前置3事(co-creation预对齐目标/成功标准/守时;评估心理安全4阶段归属→学习者→贡献→挑战;pre-survey显露出差距重置领导预期);会中动作(邀新人讲成功条件/明示期望/信息对称/直接问安全需求);框架下钻到季/月/周会。
🔗 TroopHR·领导力Offsite前3件事(HR顾问二手)
适用：③ 高管 offsite 的心理安全前置与测量，「4阶段模型+pre-survey+会中建安全动作」是可迁移。🔍 区别于卡片（团队章程/心理安全落地raganmcgill）；本卡聚焦「offsite 前/中心理安全」这一高管视角，补「心理安全作为务虚前提」缺口。

经理层难对话结构化（准备→倾听→共情精确→调解两leader·2分钟计时器）

难对话上下级二手

经理的难对话（绩效/行为/错失承诺）不可即兴。框架：①准备（先弄清情境/人/历史/可能反应；有具体事例与文档事实，模糊批评显个人化；反思自己沟通风格）；②倾听优先（分离意图/影响/误解；虚拟场景更需专注）；③共情+精确（先事实→影响→期望改变；对事不对人）；④调解两leader分歧（不强行共识，找共同目标→各方陈述立场→命名风险，中立 tone/结构，不允许打断/贬低，无效则暂停）；⑤对话后求反馈（是否产生清晰/问责/修复机会）。经理对下属难对话：用「我注意到张力…想先听你视角」非指责开场。群体冲突：可见计时器结构化轮流（每人2分钟不打断），防最大声者控场。涉及权力失衡/骚扰/内部已败→引入HR或外部。

怎么做
难对话不可即兴;框架5步(准备具体事实/倾听分离意图影响/共情+精确对事不对人/调解两leader找共同目标+中立结构+无效暂停/对话后求反馈);经理对下属非指责开场(我注意到张力想先听你);群体冲突2分钟计时器轮流防最大声控场;权力失衡/骚扰→HR或外部。
🔗 Pollack Peacebuilding·职场冲突解决(冲突调解二手)
适用：② 经理带团队 offsite 中的难对话/冲突处理，「5步框架+2分钟计时器+非指责开场」是可迁移。🔍 区别于卡片（高管冲突karstennoack/georgedupont）；本卡下沉到经理层（上下级/团队内）难对话，补「中层如何用结构化对话处理摩擦」缺口。

经理主导 Planning Offsite 落地系统（30/60/90脉冲·周脉冲检三问·CEO出席不主持）

跟进落地上下级二手

offsite 是alignment 发生地，follow-up 是 success 发生地。无结构化跟进=昂贵团建无长效。30/60/90 系统：①W1-4 周脉冲检（≤30分钟，只三问：ship了什么/卡什么/需什么帮；是解题会非状态会；把offsite承诺当客户/投资人义务）；②W5-8 60天深审（对照承诺指标，偏离则诊断为何——计划错还是执行慢，必要时调计划）；③W9-12 90天结果测（对齐是否转执行/跨职能张力是否真改善，对照offsite设的OKR）；持续节奏：季度半日mini-offsite 复校。规则：共享dashboard 可见承诺进度（不藏）；CEO 出席但不主持脉冲会（owner 是别人）；问清「漏承诺会怎样」暴露问责文化；避免5坑（范围蔓延/资深主导/模糊承诺/未处理张力/一次性事件）。

怎么做
offsite=alignment,follow-up=success;30/60/90系统(周脉冲≤30min三问ship/blocked/help非状态会/60天深审诊断计划vs执行/90天对照OKR测结果);季度半日mini-offsite复校;共享dashboard可见;CEO出席不主持;问清漏承诺后果暴露问责文化;避5坑。
🔗 Jeremy Haynes·Planning Offsite落地系统( practitioner二手)
适用：② 经理带团队 planning offsite 的 30/60/90 跟进，「周脉冲三问+CEO出席不主持+共享dashboard」是可迁移落地。🔍 区别于卡片（高管90天节奏consultclarity新团队/决策日志）；本卡下沉经理层 planning offsite 实操，补「中层如何把务虚转执行」缺口。

团队章程工作协议坊（5域·含违规处置条款·季度复访·活文档）

团队契约上下级二手

隐性规范是团队失能主源。团队章程（working agreement）让「如何共事」显性化、团队拥有、随变复访。适用时机：组队时/重大人员变动后/retro 暴露反复违规/新举措需不同协作方式。5域工作坊（2-3h）：①目的使命（在这干嘛/客户是谁/6月成功样）；②工作规范（核心时段/急事怎么处理/会议哲学）；③决策（谁能单独决/需团队input/需领导）；④沟通（什么渠道/异步响应预期）；⑤反馈冲突（怎么给反馈/怎么处理分歧/retro 承诺）。关键：文档化并发布（团队页/置顶Slack/wiki，非无人看的纪要）；章程写「违规时我们做____」给牙齿（常被跳过）；季度复访（半年前对的现在未必对）；领导也受章程约束。隐性规范显性化=共享契约人人可互hold。

怎么做
隐性规范=团队失能主源;章程坊5域(目的使命/工作规范/决策权/沟通/反馈冲突)2-3h;文档化发布(团队页/置顶wiki非纪要);必写违规处置条款给牙齿;季度复访;领导也受约束;隐性规范显性化=共享契约互hold。
🔗 Ragan McGill·高绩效团队Playbook(工程领导力二手)
适用：② 经理带团队 offsite 的「团队章程」产出，「5域工作坊+违规处置条款+季度复访」是可迁移。🔍 区别于卡片（心理安全前置troophr/团队契约）；本卡=「把章程做成offsite具体产出动作」，补「中层务虚落团队契约」缺口。

混合团队 Offsite 远程声音平权 playbook（remote advocate·轮次发言·会前共享文档·remote-first check）

混合执行上下级二手

混合 offsite 失败因远程者不觉得在房间里（听侧聊/漏视觉/难插快讨论）。playbook：①清晰会议形（议程标远程参与点，何时远程发声、房间何时停听）；②技术给平等在场（好音频/稳定视频/远程专用屏常显其脸，防afterthought）；③指派 Remote Advocate（从远程视角监测延迟/漏问/被忽略，signal 引导师，保远程声被护）；④轮次贡献（快讨论用轮流，每人先说一次再深探，防强声控场）；⑤会前共享全部文档（同起点，省解释）；⑥不依赖物理空间的活动（用数字板人人同速写/投/建）；⑦每段结尾 remote-first check（问远程还有无想法，防音频延迟漏）。度量：参与度/远程反馈/决策质量。

怎么做
混合offsite失败因远程不在场;playbook7招(清晰会议形标远程点/技术给平等在场+远程专用屏/Remote Advocate护声/轮次发言防强声控场/会前共享文档同起点/活动不依赖物理空间/段尾remote-first check);度量参与度+远程反馈+决策质量。
🔗 PlanRetreat·混合团队Offsite playbook(活动策划二手)
适用：② 混合/分布式团队 offsite（经理带本地+远程成员），「Remote Advocate+轮次发言+remote-first check」是可迁移平权。🔍 区别于卡片（虚拟团队offsite Slack/R30）；本卡聚焦「混合（本地+远程同场）远程声音平权」这一更常见场景，补「混合offsite怎么不让远程掉线」缺口。
